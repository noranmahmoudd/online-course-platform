# Online Course Platform — Backend

Express + MongoDB (Mongoose) REST API using ES Modules.

```bash
npm install
cp .env.example .env     # then fill in the values
npm run dev              # http://localhost:5000
npm run seed             # optional demo data
```

Demo accounts created by `npm run seed` (password `Password123`):
`instructor@example.com` and `student@example.com`.

See the root `README.md` for the full documentation.
